# Ex. No. 3: Implement Flexible UI Layouts using Fragments and Dynamic UI
**Register No:** URK23CS1278

## Aim
To develop a Warehouse Inventory Management Android application using Kotlin, Jetpack Compose, Fragments, and a shared `ViewModel`.

## Files Included
- `MainActivity.kt`: Hosts Fragment transactions.
- `InventoryViewModel.kt`: Shared ViewModel holding inventory state.
- `InventoryFragment.kt`: UI displaying product summaries and status cards.
- `AddProductFragment.kt`: UI form to add new products dynamically.
